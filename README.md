# A2AS Discord Project
A project created to support my A2AS autonomous racing series in Automobilista 2 using a Discord application.
## What does/will it do?
The main aim of the project is to create an application that will automate and enhance various aspects of the A2AS racing series, managing finances, driver markets, car development and more.
## What's currently available?
Currently, no aspects have been created, as the project is new, but work is already underway!
## What language(s) does the project use?
The Discord application will use Python, as it's the most widely documented SDK available. Java was considered, but it's limited information would be too challenging, and it has fewer features.
It also uses SQL, JSON and YAML for different storage solutions depending on the circumstances. YAML is mainly used for static key-values, JSON for larger static objects and SQL for dynamic variables and larger groups of data.
